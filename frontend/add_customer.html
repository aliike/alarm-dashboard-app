Müşteri Ekle

Bu alan zorunludur. Şirket / müşteri görünen adı.
Bu AWS hesabının görünen adı. Boş bırakılırsa müşteri adı kullanılır.
Tam 12 haneli rakam olmalı. Müşterinin ana AWS hesap ID'si.
Format: arn:aws:iam::<12 hane>:role/<isim> Account ID girilince otomatik doldurulur.
İptal
IAM Kurulum Rehberi
1
Hesap tipini belirleyin
Bu hesap bir AWS Organizations yönetici (Payer/Management) hesabı mı, yoksa bağımsız bir AWS hesabı mı?
Standalone: Yalnızca bu hesap izlenir. Sadece CloudWatch ve EC2 izinleri gereklidir.
Payer account seçildi. Organization'daki tüm alt hesaplara da AlarmDashboardRole oluşturmanız gerekecek. Alt hesaplar otomatik keşfedilecektir.
2
EC2 Instance Profile'ı kontrol edin
Bu dashboard'un çalıştığı EC2 instance'ın IAM role'ü, müşteri hesaplarına AssumeRole yapabilmek için şu yetkiye sahip olmalıdır: 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "sts:AssumeRole",
      "Resource": "arn:aws:iam::*:role/AlarmDashboardRole"
    }
  ]
}
3
Müşteri hesabında IAM Role oluşturun
Müşteri AWS hesabında şu adımları takip edin:
  1. AWS Console → IAM → Roles → Create role
  2. Trusted entity: Another AWS account
  3. Role adı: AlarmDashboardRole

                        Her member hesaba elle girip role oluşturmanıza gerek yok.
                        CloudFormation StackSets ile payer hesabından
                        tek seferlik deploy yaparak tüm Organization'a yayabilirsiniz.
                        Sonradan katılan yeni hesaplara da otomatik uygulanır.
                    


                    
                    

                        

                            Member hesaplar için template (organizations:* izni olmadan):

                            izinlerini içerir.
